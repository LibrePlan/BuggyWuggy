# Data for the license page

- `big-mac-source-data-v2.csv`: The Economist's Big Mac index, source data, from
  <https://github.com/TheEconomist/big-mac-data/blob/master/source-data/big-mac-source-data-v2.csv>,
  downloaded 2026-11-13. © The Economist, licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Unchanged. To update, download
  the file again and replace this one; BuggyWuggy uses the rows of the latest date.
- `country-codes.json`: countries with their ISO 3166-1 alpha-2 code and international dialling
  code (`name`, `code`, `dial_code`).
